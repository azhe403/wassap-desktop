# Privacy Blur Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adopt the MIT-licensed WhatsApp Privacy Blur engine into Wassap Desktop so every WebView2 session blurs sensitive WhatsApp Web content (hover-to-reveal), controlled from the app's own Settings page and a sidebar shield toggle.

**Architecture:** The upstream engine (`selectors/*.js` + `content.js`) is vendored byte-identical into a new `internal/privacyblur` package and injected as one document-created script via go-webview2's `Chromium.Init` (the same precedent as the account-label injection). A small adapter of ours fakes the `chrome.*` API surface the engine uses, bridging upstream's storage to the app's `config.json` via a boot JSON baked at session creation plus live `Chromium.Eval` re-applies. Controls are native: a Privacy Blur section in Settings and a shield button in the sidebar. The add-on's in-page panel, floating shield and sidebar minimizer are deliberately not ported (user decision 2026-11-16).

**Tech Stack:** Go 1.26, Wails v2.17.0, `github.com/wailsapp/go-webview2` v1.0.22, Win32, vanilla HTML/CSS/JS frontend, WebView2.

**Spec:** `docs/superpowers/specs/2026-11-16-privacy-blur-design.md` (approved 2026-11-16, commit 0b135b5). Read it before starting.

## Global Constraints

- Windows-only behavior; other platforms must keep compiling via `app_other.go` stubs (no behavior change there).
- Upstream vendored pinned at **v3.2.0, commit `82cc20e0`** of `https://github.com/Nyihui/WhatsappPrivacyBlur-Extension` (2026-11-14, MIT "Copyright (c) 2026 Nyihui"). Upstream files are byte-identical; all adaptation lives in `internal/privacyblur/assets/adapter.js` (ours).
- Settings key names mirror upstream `DEFAULT_SETTINGS` exactly (see spec §4.2), minus the deliberately dropped `minimizerEnabled`, `shortcutToggleMinimizer`, `shortcutToggleShield` rebinding metadata.
- Master switch defaults **OFF**; global setting across all accounts; `Alt+/` is the fixed in-page shortcut; Settings labels in English; mode is `blur` | `redacted`.
- No new module dependencies anywhere.
- Commits: conventional format, one logical change per commit (`feat(privacyblur): ...`, `feat(config): ...`, `feat(webview2): ...`, `feat(app): ...`, `feat(frontend): ...`, `docs: ...`).
- `go test ./...` must stay green; frontend has no test runner — its checks are manual QA (Task 6).
- Do not touch `frontend/dist/` (gitignored, regenerated by `npm run build`).
- Vendoring note: repo has no `.gitattributes` and `core.autocrlf=true`; never assert byte hashes in tests against checked-out files. Sentinel-string tests only.
- Spec §8 records which decisions the author made vs. which the user made; do not revisit them.

## Review Focus

Failure modes the spec implies but no task's happy-path tests exercise, most likely first:

1. **Stale blur state after a hard reload / renderer crash inside a long-lived session** (boot JSON was baked at session creation) → pinned by Task 1 (`ApplyScript` carries the *current* JSON) and Task 3 (re-apply on every `NavigationCompleted`).
2. **In-page `Alt+/` toggling racing a Settings-page save** → pinned by Task 2 (`MergePrivacyBlurSettings` race test run with `-race`).
3. **A `PrivacyBlurConfig` arriving from JS with zero values** (absent fields over Wails decode as zero: `blurAmount: 0`, `privacyMode: ""`) → pinned by Task 2 (clamp tests on `Set` and `Merge`) and Task 4 (frontend always round-trips the whole struct from `Get`).
4. **Upstream re-sync silently shipping a broken engine** (missing file, truncated copy, wrong order) → pinned by Task 1 (presence/order/sentinel test over the embedded set).
5. **Two open sessions disagreeing after one settings change** (broadcast missed a session) → pinned by Task 6 QA checklist step 4; Task 3 review must confirm every `Session` in `h.sessions` is reached by `EvalAll`.

- [ ] **Step 5: Write `assets/adapter.js`** (ours — exact content):

```js
/* Wassap Desktop adapter: bridges the vendored engine's chrome.* API to the app's config.
   Never replace window.chrome — WebView2 owns chrome.webview. Augment only. */
(function () {
  'use strict';
  var boot = window.__WA_PRIVACY_BOOT || {};
  var changedListeners = [];

  function fireChanged(changes) {
    for (var i = 0; i < changedListeners.length; i++) {
      try { changedListeners[i](changes, 'local'); } catch (e) { /* engine hook must not break us */ }
    }
  }

  var local = {
    get: function (defaults, cb) {
      var out = {};
      var keys = (defaults && typeof defaults === 'object' && !Array.isArray(defaults)) ? Object.keys(defaults) : [];
      for (var i = 0; i < keys.length; i++) {
        out[keys[i]] = Object.prototype.hasOwnProperty.call(boot, keys[i]) ? boot[keys[i]] : defaults[keys[i]];
      }
      if (typeof cb === 'function') cb(out);
    },
    set: function (obj, cb) {
      var changes = {};
      if (obj && typeof obj === 'object') {
        for (var k in obj) {
          if (Object.prototype.hasOwnProperty.call(obj, k)) {
            boot[k] = obj[k];
            changes[k] = { oldValue: undefined, newValue: obj[k] };
          }
        }
        try {
          window.chrome.webview.postMessage(JSON.stringify({ kind: 'privacy-blur-set', values: obj }));
        } catch (e) { /* host routing is best-effort */ }
        fireChanged(changes);
      }
      if (typeof cb === 'function') cb();
    }
  };

  window.chrome = window.chrome || {};
  window.chrome.storage = window.chrome.storage || {};
  window.chrome.storage.local = local;
  window.chrome.storage.onChanged = {
    addListener: function (fn) { if (typeof fn === 'function') changedListeners.push(fn); }
  };
  window.chrome.runtime = window.chrome.runtime || {};
  if (!window.chrome.runtime.onMessage) {
    window.chrome.runtime.onMessage = { addListener: function () {} };
  }

  window.__wassapPrivacyApply = function (json) {
    try {
      var next = (typeof json === 'string') ? JSON.parse(json) : json;
      if (!next || typeof next !== 'object') return;
      for (var k in next) {
        if (Object.prototype.hasOwnProperty.call(next, k)) boot[k] = next[k];
      }
      if (typeof window.applySettings === 'function') {
        window.applySettings(Object.assign({}, boot));
      }
    } catch (e) { /* never break the page */ }
  };
})();
```

- [ ] **Step 6: Implement `privacyblur.go`**

```go
// Package privacyblur embeds the vendored WhatsApp Privacy Blur engine and the
// Wassap Desktop adapter that bridges it to the app's config store. The engine
// is MIT-licensed upstream; see assets/SYNC.md.
package privacyblur

import (
	"embed"
	"io/fs"
	"strings"
)

//go:embed all:assets
var assets embed.FS

// manifestOrder is the load order from upstream manifest.json (document_start).
var manifestOrder = []string{
	"selectors/index.js", "selectors/avatars.js", "selectors/names.js",
	"selectors/text.js", "selectors/previews.js", "selectors/input.js",
	"selectors/media-preview.js", "selectors/media-gallery.js", "selectors/misc.js",
	"content.js",
}

func PreludeScript(settingsJSON string) string {
	var b strings.Builder
	b.WriteString("window.__WA_PRIVACY_BOOT = ")
	b.WriteString(settingsJSON)
	b.WriteString(";\n")
	mustWrite(&b, "assets/adapter.js")
	for _, rel := range manifestOrder {
		b.WriteString("\n/* vendored: " + rel + " */\n")
		mustWrite(&b, "assets/upstream/"+rel)
	}
	return b.String()
}

func ApplyScript(settingsJSON string) string {
	return "window.__wassapPrivacyApply(" + settingsJSON + ");"
}

func mustWrite(b *strings.Builder, name string) {
	data, err := fs.ReadFile(assets, name)
	if err != nil {
		panic("privacyblur: embedded asset missing: " + name)
	}
	b.Write(data)
}
```

Concern: `PreludeScript` test reads vendored files from disk, but `PreludeScript` itself uses embed — same files, same bytes. JSON note: `encoding/json` escapes `<`, `>`, `&` to \u003c etc., so `</script>`-style breakouts cannot occur inside the boot object. The settingsJSON comes from `json.Marshal` only (never hand-built).

func (a *App) handlePrivacyBlurWrite(values map[string]any) {
	defer func() {
		if r := recover(); r != nil { log.Printf("privacy blur: write hook panic: %v", r) }
